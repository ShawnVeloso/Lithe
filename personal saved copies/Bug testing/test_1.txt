>>> RESPONSE : Scanning your entire `C:\` drive indiscriminately is a terrible idea for three reasons:

1. **Permission Hell:** You will constantly hit system/protected directories (`C:\Windows`, `System Volume Information`, `C:\ProgramData`) that throw `PermissionError` exceptions and slow down execution.
2. **Junk Overload:** You'll end up with tens of thousands of internal app icons, cached web thumbnails, UI assets, and telemetry images instead of your actual photos/media.
3. **Performance Disk Thrashing:** Scanning millions of system files sequentially in Python takes unnecessary time and disk I/O.

If you actually want your personal image files, target `C:\Users\` instead. 

If you insist on scanning `C:\`, the script below uses `os.walk` with a blacklist of system directories to skip, catches access errors gracefully, and filters for common image extensions.

```python
import os
from pathlib import Path

# Common image extensions (case-insensitive)
IMAGE_EXTENSIONS = {
    ".jpg", ".jpeg", ".png", ".gif", ".bmp", 
    ".webp", ".tiff", ".svg", ".heic", ".raw"
}

# Directories to skip to prevent access errors and junk results
EXCLUDE_DIRS = {
    "Windows",
    "Program Files",
    "Program Files (x86)",
    "ProgramData",
    "System Volume Information",
    "$Recycle.Bin",
    "AppData",
    "node_modules",
    ".git"
}

def scan_for_images(start_dir="C:\\"):
    found_images = []
    
    print(f"Scanning starting from: {start_dir}...\n")
    
    for root, dirs, files in os.walk(start_dir, topdown=True):
        # Modify dirs in-place to prune excluded directories from traversal
        dirs[:] = [d for d in dirs if d not in EXCLUDE_DIRS and not d.startswith("$")]
        
        for file in files:
            ext = os.path.splitext(file)[1].lower()
            if ext in IMAGE_EXTENSIONS:
                full_path = os.path.join(root, file)
                found_images.append(full_path)
                print(full_path)

    print(f"\nDone. Found {len(found_images)} images.")
    return found_images

if __name__ == "__main__":
    # Change start_dir to r"C:\Users" for a much faster, relevant search
    scan_for_images(start_dir=r"C:\Users")
```
